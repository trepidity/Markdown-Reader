# Rust comparison round

The user authorized a fully Rust comparison independent of the Go core. Keep it
in this directory; the Go product and previous comparison remain baselines.
All five UI frameworks consume the same Rust JSON command dispatcher and parsed
presentation. Product seams: dispatcher responses, rendered presentation blocks,
actual temporary files, and bundled apps launched with open and keyboard actions.
Use existing comparison fixtures. Never equate core tests with native UI proof.
