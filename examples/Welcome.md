# A quieter place for words

Markdown Reader keeps the document at the center. Read first, then press **⌘E** whenever you want to write.

> Good tools make room for the work.

## From thought to page

Your edits are saved as you type. Undo is saved too, so the file on disk follows what you see in the editor.

- **Preview by default** — a calm, focused reading surface
- **Four themes** — Paper, Night, Sepia, and System
- **Three reading styles** — literary, modern, and technical
- **Recent files** — pick up where you left off

## Small details, considered

| Shortcut | Action |
| :--- | :--- |
| ⌘O | Open a file or folder |
| ⌘E | Toggle edit and preview |
| ⌘Z | Undo |
| ⇧⌘Z | Redo |
| ⇧⌘S | Save a copy |
